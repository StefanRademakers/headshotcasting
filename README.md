# AI Casting Headshot Generator

A first V1 React + TypeScript app for generating data-driven photorealistic character profiles and headshot prompts.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## What is included

- Region-weighted visual profiles
- Age, gender, campaign and region controls
- Generated character profile JSON
- Photorealistic headshot prompt builder
- Negative prompt builder
- Copy buttons for JSON and prompts

## Important design principle

Region/culture influences weighted probabilities, not fixed stereotypes.
The generator should create believable individual people, not caricatures.
